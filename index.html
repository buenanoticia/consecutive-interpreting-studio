経過時間: 00:00
Stage 1: Memory Without Notes

短期記憶保持（リテンション）＆映像化トレーニング

【訓練の目的】 ノートを取らずに音声を聴き、頭の中に「情景（誰が・何を・どうしたか・数値）」を映像として思い浮かべてから、原語または日本語でそのまま再現（リプロダクション）します。ダニエル・ジルのモデルにおける L（聴解分析） と M（短期記憶） の基礎体力を養います。

脱言語化（Deverbalization）チェックシート

音声を聴いた直後に、言語の形を離れて以下の4要素が脳内に浮かんでいるか入力・確認しましょう。

Stage 2: Sight Translation (順送り訳)

スラッシュ・リーディング＆高速サイトラ訓練

【訓練の目的】 英語・台湾華語・スペイン語（SVO語順）を後ろから返り読みせず、意味の切れ目（チャンク）ごとに前から順送りで日本語へ変換する回路を作ります。「次のチャンク →」を押しながら声に出して訳し、クリックで順送り訳を確認してください。

ペースメーカー（自動チャンク送り）

指定した秒数ごとに次のチャンクをハイライトします。目を前に戻さず訳し切るスピード訓練に最適です。

順送りサイトラの3原則
  • 主語＋動詞を名詞化・接続化：「政府は決定した → 政府が決定したのは〜」と繋ぎ、文末まで待たない。
  • 関係代名詞・修飾節は後から説明：「〜な企業」ではなく「企業、それは〜ですが」と順送りで処理する。
  • 品詞の柔軟な変換：原語の名詞を動詞に、受動態を能動態に柔軟に組み替える。

Stage 4: Full Consecutive & Evaluation

本番形式・逐次通訳＆トランスクリプト照合

1. 上部の「▶ スピーチ音声再生」で全文を聴きながらノートを取ります。
2. 音声終了後、「訳出を録音」を押して自分のノートだけを見ながら日本語（または目標言語）へ訳出します。
3. 下の欄に自分の訳出メモを入力するか録音した音声を聴き返し、原文・模範訳および必須キーワードと照合します。

模範訳例（Model Target Interpretation）

ダニエル・ジル「認知負荷モデル」自己診断ルーブリック

録音した自分の訳出を聴きながら5段階で採点すると、今どのEffort（負荷）がボトルネックになっているか診断します。

1. 情報の正確性・数値の再現 (Fidelity / L+M) 3 / 5
数値、固有名詞、否定・肯定の逆転ミスがなかったか
2. 論理の繋がり・接続関係 (Coherence / Links) 3 / 5
因果（だから）・逆接（しかし）が明確に再現されたか
3. ノート読解のスムーズさ (Note-Reading / N) 3 / 5
自分のメモが解読できずに詰まる箇所がなかったか
4. デリバリー・流暢さ (Delivery & Poise / P) 3 / 5
「えー」「あのー」のフィラーや不自然な言い直しが少なかったか
